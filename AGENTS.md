# AGENTS — ДЗ 2, Taraxacum

Сначала прочитай INDEX.md, STATUS.md и задачу в tasks/.
Проект проверяет согласованность координат и длин LSC/SSC/IR трёх пластомов.

## Проверка из корня проекта

```bash
python3 checks/check_plastome_consistency.py
python3 scripts/hw2_synthetic_and_k4.py
```

Обе команды возвращают 0 при успехе. Повреждённые входы отклоняются верификатором.
Используется только стандартная библиотека Python 3. Новые пакеты не устанавливать.
Исходные CSV и критерии METHOD.md не изменять. Проверки не ослаблять ради кода 0.
Сеть, пересчёт деревьев и биологическая интерпретация границ не входят в задачу.
Работай на копиях для экспериментов; diary.md только дописывай.
STATUS.md отражает текущее состояние; «принята» ставит только пользователь.
После двух неудач подряд по одной причине остановись и объясни причину.
Коммиты и публикация — в пределах явного запроса пользователя.
