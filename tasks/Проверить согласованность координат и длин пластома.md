# Проверить согласованность координат и длин LSC, SSC, IR у трёх пластомов

Запрос пользователя: построить верификатор согласованности координат и длин LSC, SSC и двух
копий IR у трёх пластомов (KU361241.1, KU736960.1, NC_032056.1). Вычислительное направление B,
не меньше пяти содержательных свойств. Методика записывается до первого прогона; проверка
запускается одной командой и выносит вердикт; результат воспроизводится по метке git.

Готово, когда:
- `METHOD.md` закоммичен до первого прогона верификатора (коммит методики раньше результатов);
- верификатор в `checks/` запускается одной командой из `AGENTS.md` и возвращает код 0 на
  корректных данных, код 1 на повреждённых;
- реализовано не меньше пяти содержательных свойств из `METHOD.md`;
- в `results/` есть вывод «до» (проверка падает) и «после» (проходит) внесённой ошибки;
- эксперимент К4: 5 фиксированных seed, парное сравнение, интервал, практический порог;
- дерево подцелей (не меньше трёх) и журнал попыток с отметкой правила трёх попыток;
- `diary.md` дописан, `STATUS.md` обновлён.

Не входит: не изменять исходные FASTA, `homework/structure/ir_boundaries.csv`,
`results/hw1/fasta_stats.csv` и существующие файлы `checks/`; не снимать защиту существующих
файлов `checks/`; не пересчитывать деревья; не запускать сетевые запросы; не писать итоговый
отчёт и не ставить метку `hw2` на этом этапе.

## Итог

Реализован верификатор `[[checks/check_plastome_consistency.py]]` (стандартная библиотека):
свойства 1–7 из METHOD.md. Контроль версии (SHA-256) и проверка содержимого разделены;
проверка содержимого не требует совпадения SHA-256 (для синтетических и повреждённых копий).
Свойство 7 использует вычисленные длины IR1/IR2; смысл знака `ir_copy_length_difference` не
выдумывается — при 0 проверяется равенство длин IR, при ненулевом «семантика поля не
определена, проверка не завершена» (ненулевой код).

Скрипт `[[scripts/hw2_synthetic_and_k4.py]]`: 13 синтетических примеров (2 положительных,
11 отрицательных) и эксперимент К4 (5 seed × 100 повреждённых копий, сбалансированных по
5 типам, 500 корректных контролей, парный bootstrap 1000 повторов, seed 42).

Результаты в `[[results/hw2/]]`: `verdict_ok.txt` (код 0), `caught_error_before.txt` (код 1,
свойства 3, 4, 6, 7), `synthetic_examples.txt` (все 13 OK), `k4_experiment.csv` (1000 строк),
`k4_summary.txt` (полная 1.0000, простая 0.2380, ложных срабатываний 0, парная разность
0.7620, интервал [0.7220, 0.7980], порог 10 п.п. достигнут), `goal_tree.md`, `attempts_log.md`.

Команда запуска: `python3 checks/check_plastome_consistency.py` (код 0 на корректных данных,
ненулевой на повреждённых); `python3 scripts/hw2_synthetic_and_k4.py` (код 0 при прохождении).
Обе команды добавлены в `[[AGENTS.md]]` (раздел 1).
