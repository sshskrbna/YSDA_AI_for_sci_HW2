# Дерево подцелей — верификатор согласованности пластома

ДЗ 2 «Проверка», вычислительное направление B. Дерево подцелей сложной проверки
(не меньше трёх подцелей).

```
Верификатор согласованности корректен
├── данные соответствуют договору (свойство 1)      — проверка схемы, типов, наборов образцов
│   └── сопоставление sample_id ↔ accession         — фиксированная таблица, отклонение неизвестных и дубликатов
├── координаты образуют корректное разбиение (свойство 2) — проверка порядка и границ
├── длины областей согласованы с координатами (свойства 3–6) — тождества lsc/ssc/IR1/IR2, разность IR
└── сумма длин равна полной длине (свойство 7)      — lsc+IR1+ssc+IR2 = length_bp
```

## Чем закрыта каждая подцель

| Подцель | Чем закрыта | Попыток |
|---|---|---|
| Свойство 1 (схема, типы, наборы образцов) | `verify_content` в `checks/check_plastome_consistency.py`; синтетические примеры `neg_unknown_id`, `neg_duplicate` | 1 |
| Свойство 2 (порядок координат) | `verify_content`; синтетические примеры `neg_ir1_start_1`, `neg_ir2_end_ne_length` | 1 |
| Свойства 3–6 (длины областей, разность IR) | `verify_content`; синтетические примеры `neg_lsc_mismatch`, `neg_ir_bp_mismatch`, `neg_ssc_mismatch`, `neg_ir_lengths_differ_diff0`, `neg_nonzero_diff` | 1 |
| Свойство 7 (сумма длин) | `verify_content`; синтетический пример `neg_sum_ne_length` | 1 |
| Эксперимент К4 (сила проверки) | `scripts/hw2_synthetic_and_k4.py`: 500 повреждённых копий, 500 контролей, парный bootstrap | 1 |
