# ДЗ 2 «Проверка» — Taraxacum

Верификатор согласованности координат и длин LSC, SSC и двух копий IR у трёх пластомов.
Отдельный пакет курса «ИИ-ассистенты для исследователя. AI4Science».

## Запуск

Python 3, только стандартная библиотека. Из корня проекта:

```bash
python3 checks/check_plastome_consistency.py
python3 scripts/hw2_synthetic_and_k4.py
```

Ожидается код 0 у обеих команд. Верификатор отклоняет повреждённые данные с ненулевым кодом.

## Данные и результаты

- `homework/structure/ir_boundaries.csv` — координаты и длины областей.
- `results/hw1/fasta_stats.csv` — полные длины, перенесённые из ДЗ 1; путь сохранён для воспроизводимости.
- `results/hw2/` — 13 синтетических примеров, эксперимент по обнаружению 500 повреждений,
  вывод «до/после», дерево подцелей и журнал попыток.

Проверяется согласованность таблиц, а не биологическая правильность определения границ.
Метка `hw2` пока не создана.
